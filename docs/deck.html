afterimage

A visual inspection agent that remembers. It aligns every photo to the stored baseline of the same asset with OpenCV 5, and a measured number decides what it does next.

Solution

An agent that keeps the memory of each asset and acts on the difference.

Six OpenCV 5 tools over MCP, in an arm64 container on AWS Lambda (Graviton). Memory in DynamoDB and S3. Gemini orders the tool calls and phrases the result; it cannot move a threshold or skip a step. Every decision is a hash-chained trace event: {metric, value, threshold, branch}.

Limits and what's next

What it does not claim.

  • Dataset, not field accuracy. The figures hold for the committed dataset; plant imagery outside it is the next step.
  • Solar only is measured. The metal and concrete sets are demonstrations with one synthetic defect each.
  • Five scenarios fail, each traced to a cause: a global coverage default, the exposure gate firing late, severity ignoring the class, a soiling rule tuned on synthetic texture.
  • The hash chain detects ordinary edits; it is not a signed audit log. The public demo has no login.
